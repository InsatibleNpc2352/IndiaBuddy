## 2024-05-24 - Zustand Destructuring\n**Learning:** Destructuring the Zustand store objects (like `const { property } = useStore();`) causes the component to re-render whenever *any* property in the store changes, rather than just the one accessed. This is explicitly contrary to the guidelines which recommend `useStore(state => state.property)` to isolate re-renders.\n**Action:** Always use individual selectors for each piece of state accessed from Zustand to minimize unnecessary re-renders in Next.js applications.
